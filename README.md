# RAG-система для семантического поиска по корпоративным документам

Программный модуль интеллектуального поиска, построенный на архитектуре **Retrieval-Augmented Generation (RAG)**. Система позволяет задавать вопросы на естественном языке по внутренней документации компании и получать точные ответы со ссылками на первоисточники — без передачи данных во внешние сервисы.

## Решаемая проблема

В компаниях знания разрознены по десяткам документов: регламенты, инструкции, wiki, технические описания. Классический поиск по ключевым словам не понимает смысл вопроса и выдаёт нерелевантные результаты при перефразировании. Публичные нейросети (ChatGPT и аналоги) неприменимы из-за рисков утечки коммерческой тайны.

## Возможности

- 📚 Загрузка документов в форматах TXT, MD (PDF и DOCX — в разработке)
- 🔍 Семантический поиск по смыслу с пороговым отсечением нерелевантных ответов
- 📏 Вывод расстояний для оценки уверенности системы
- 🔒 Локальное развёртывание — данные не покидают периметр предприятия
- 🌐 Поддержка русского языка

## Технологический стек

- **Python 3.14** — основной язык
- **ChromaDB** — векторная база данных
- **Sentence-Transformers** — модель `paraphrase-multilingual-MiniLM-L12-v2` для эмбеддингов
- **SQLite** (планируется) — реляционная БД для метаданных и журнала запросов


## Установка и запуск

### Требования
- Python 3.11 или выше
- Git

### Шаги
```bash
# 1. Клонировать репозиторий
git clone https://github.com/ReloaDeeD/vik-rag-system.git
cd vik-rag-system

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

# 3. Установить зависимости
pip install chromadb sentence-transformers

# 4. Запустить поиск
python first_search.py

Первый запуск скачает модель эмбеддингов (~500 МБ), последующие запуски выполняются быстро.
