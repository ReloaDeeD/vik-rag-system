# RAG-система для семантического поиска по корпоративным документам

Программный модуль интеллектуального поиска, построенный на архитектуре **Retrieval-Augmented Generation (RAG)**. Система принимает вопросы на естественном языке по внутренней документации компании и возвращает точные ответы со ссылками на первоисточники — без передачи данных во внешние сервисы.

## Решаемая проблема

В компаниях знания разрознены по десяткам документов: регламенты, инструкции, wiki, технические описания. Классический поиск по ключевым словам не понимает смысл вопроса и выдаёт нерелевантные результаты при перефразировании. Публичные нейросети (ChatGPT и аналоги) неприменимы из-за рисков утечки коммерческой тайны.

## Возможности

- Загрузка документов в форматах TXT, MD (PDF и DOCX — в разработке)
- Гибридный поиск: BM25 + векторный + RRF + LLM re-ranking
- Генерация ответов локальной LLM (Ollama, qwen2.5:3b) строго по найденному контексту
- Указание источника в ответе: имя файла и номер фрагмента
- Пороговое отсечение нерелевантных ответов
- Веб-интерфейс (Streamlit) для удобства использования
- Автоматическая оценка качества: тестовый датасет (40 вопросов) и метрики (Context Precision, Faithfulness, Answer Relevancy)
- Локальное развёртывание — данные не покидают периметр предприятия
- Поддержка русского языка

## Технологический стек

- **Python 3.14** — основной язык
- **ChromaDB** — векторная база данных (коллекция `corp_docs`)
- **Sentence-Transformers** — модель `paraphrase-multilingual-MiniLM-L12-v2` для эмбеддингов
- **SQLite** — реляционная БД метаданных и журнала запросов (таблицы `documents`, `chunks`, `query_log`)
- **Ollama + qwen2.5:3b** — локальная LLM для генерации ответов и re-ranking
- **rank-bm25** — классический текстовый поиск для гибридного режима
- **Streamlit** — веб-интерфейс

## Установка и запуск

### Требования
- Python 3.11 или выше
- Git
- Ollama (https://ollama.com/download)

### Шаги
```bash
# 1. Клонировать репозиторий
git clone https://github.com/ReloaDeeD/vik-rag-system.git
cd vik-rag-system

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать БД метаданных
python init_db.py

# 5. Проиндексировать документы
python indexer.py docs

# 6. Скачать модель LLM
ollama pull qwen2.5:3b

# 7. Запустить поиск (терминальный режим)
python generate_answer.py "ваш вопрос"

# 8. Запустить веб-интерфейс (в отдельном терминале)
streamlit run app.py
